# 社区镜像仓库浏览

镜像页的“社区镜像 → 添加社区镜像”可以浏览 Docker Hub、Quay 和 OCI Distribution 仓库的标签。浏览仅获取标签元数据，不下载镜像层，也不自动将所有标签导入镜像目录。

管理员通过 `image_community_catalog` 配置仓库卡片。混合多个引擎或硬件的仓库可以省略 `engine` 和 `framework`。选择标签时，标签中明确声明的引擎、引擎版本、框架、框架版本和 CPU 架构会自动回填；标签信息优先于仓库默认值，用户仍可修改。切换标签会清除无法从新标签识别的旧版本，未知架构恢复为 `multi`。

例如 `cann9.0-sglang0.5.15.post1-arm64-diffusion-slot16` 回填 SGLang `0.5.15.post1`、CANN `9.0` 和 `arm64`；vLLM 标签中的独立 `omni` 标记按 `vllm-omni` 镜像家族处理。缺少版本信息的 `latest` 等标签不会被填入猜测的框架版本。

没有统一默认值的混合仓库，会在后台读取标签元数据，最多同时请求两个仓库，并根据仍在上游的标签汇总引擎和框架徽标；不下载镜像层，也不新增持久化的能力清单。读取失败时卡片显示失败提示，点击仓库仍可重试。这些回填值和徽标描述标签声明，不代替镜像内部组件或真机兼容性验证。

Docker Hub 使用 `hub.docker.com` 的标签 API，Quay 使用其公开标签 API。二者仍按公开仓库浏览，私有 Hub/Quay API 的专用认证不属于这次支持范围。

OCI 仓库浏览读取平台已有的主机凭据设置，使用对应仓库的用户名和密码。支持直接 Basic 认证，以及同一 HTTPS 主机上的 Bearer token 交换。凭据不进入仓库卡片、镜像目录或 API 返回值。

认证限定在仓库的准确 HTTPS 主机和端口；自定义 API 地址、跨主机 token 服务、分页与 HTTP 重定向不能获得该仓库的密码或 Bearer token。跨主机分页与带认证的跨来源重定向会失败。需要不同主机认证服务的私有 OCI 仓库仍需另行适配。

成功的标签列表缓存一小时。修改或删除登录信息会使原凭据对应的私有列表缓存失效；查询失败不会作为成功列表缓存。上传中的新标签可能在缓存过期后才出现。

浏览、登记、拉取和推理是不同步骤。选择标签并添加后，镜像出现在社区目录；部署仍需匹配的硬件、架构、驱动、模型和启动模板。
