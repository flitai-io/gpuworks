# 控制台页面导览

Web 控制台是一个单页应用，随 server 二进制一起提供。本页按左侧菜单的分组列出全部页面：页面名使用界面上的中文文案，路径是浏览器地址栏里的路径（前端路由），「页内」描述的是同一路径下的标签页、抽屉和弹窗。路由定义在 `ui/src/App.tsx`，菜单定义在 `ui/src/navigation.tsx`，文案在 `ui/src/i18n/locales/zh/`。

约定：

- 「页面名」取菜单项文案；页面标题与菜单文案不同时单独写明。
- 详情页没有菜单项，只能从列表进入，归在所属菜单下。
- 带 `:` 的路径段是变量；`/inference-templates/*` 中的 `*` 是形如 `org/model` 的带斜杠模型 ID。
- 菜单高亮只看路径第一段，所以 `/monitor/d/3` 仍高亮「监控中心」。

## 全局外壳

顶栏标题默认由产品名称和「集群管理平台」组成，可在 **设置 → 通用 → 品牌外观**中自定义。左侧菜单最上方是「概览」，下面分五组：「监控与分析」「算力资源」「模型」「推理」「管理」。

监控与分析排在最前，然后是推理所依赖的算力资源和模型，再是推理，管理排在最后；新功能加在所属分组的末尾，已有菜单项的位置不变。菜单底部「收起菜单」可把菜单收成图标栏，状态保存在浏览器里。

| 入口 | 位置 | 用来做什么 |
|---|---|---|
| 登录控制台 | 未登录时任意路径都显示登录页；登录后访问 `/login` 会跳到 `/dashboard` | 用管理员账号登录；忘记密码见[安装和升级控制面](../how-to/install-server.md) 的 `reset-password` |
| 语言切换 | 顶栏右侧 | 切换界面语言 |
| 退出登录 | 顶栏右侧图标 | 注销当前会话 |
| 页面不存在 | 任何未定义的路径 | 提示「你访问的地址没有对应资源」 |
| `/` | 根路径 | 重定向到 `/dashboard` |
| AI 助手 | 没有独立路径：常驻右侧侧边栏，顶栏「AI 助手」或 ⌘I / Ctrl+I 打开；模型、失败实例、调度不上的部署、节点详情上的 AI 按钮会直接在侧边栏开始对应任务 | 空白时列出当前页面可做的任务并标出需要关注的对象；先显示平台检查，再流式显示 AI 分析，回答后给出推荐追问；AI 分析需先在「设置」的「AI 服务」里配置，见[使用 AI 助手](../how-to/use-ai-helper.md) |

### 设置

路径：`/settings`。页面按六个标签分组。URL 片段 `#general`、`#pull`、`#nodes`、`#access`、`#integrations`、`#data` 分别选中对应标签；卡片自己的片段（如 `#updates`、`#security`、`#telemetry`、`#pull-settings`、`#data-retention`）会打开卡片所在的标签。

#### 通用

- **品牌外观**：设置 Logo、产品名称、顶栏标题、登录页介绍文字，留空用内置默认值。仅管理员可改。
  - 选好图片后弹出裁切窗口，默认框住全图。可拖动、缩放或重新框选；勾选「裁成正方形」锁定 1:1，并预览侧栏里的实际效果。
  - 确定后，图片在浏览器里缩到 256 像素以内并压缩；未裁切且较小的 SVG 原样保留。
  - **显示位置**：侧栏 Logo 旁显示产品名称（默认 `GPUWorks`），顶栏左上角显示顶栏标题（默认「产品名称 + 集群管理平台」，跟随界面语言），浏览器标签页标题与图标也跟随产品名称和 Logo；登录页左侧显示 Logo、产品名称与介绍文字。自定义的文字原样显示，不随界面语言翻译。
- **版本与更新**：查看并更新服务端、系统镜像目录和推理模板目录。
  - 更新渠道可选正式发布版 / 滚动预览版。
  - 「自动检测新版本」开关决定 server 是否自动检查。开启时，检查向发布方报告安装标识、server 版本与 agent 版本分布；仅在同时加入用户体验改进计划时，才额外报告节点数与 GPU 型号。关闭自动检测会停止这些检查及其附带的报告；改进计划的每日报告由该计划的开关独立控制。
  - 分别显示服务端、系统镜像目录、推理模板目录的当前值与最新值。
  - 两份目录可一键更新或上传文件。服务端可在控制台升级或上传升级包，不支持时给出升级命令。
  - **页头提示**：自动检测新版本开启时，打开登录页 server 就开始检查更新（server 对同一渠道每小时最多向外检查一次；登录页本身不显示结果），登录后服务端或官方目录有新版本时页头出现「有可用更新」，点击进入设置页「版本与更新」。
- **监听地址**：写入 `server.yaml`。

#### 镜像与模型拉取

「拉取设置」包含四个标签：

- **来源规则**：镜像规则与模型站点规则；站点规则抽屉有「测试连通」。
- **代理**：有序代理条目，以及「预览节点所使用代理」。
- **同步组**。
- **凭据**：镜像仓库与模型站点两种凭据。

详见[配置镜像与模型拉取](../how-to/configure-pull-settings.md)。

#### 节点与部署

- **SSH 密钥**：平台 SSH 密钥。
- **部署**：实例启动超时的集群默认值。
- **孤儿容器清理**。

#### 安全与访问

- **安全**：两个开关，仅管理员可改。一是是否允许试验场 HTML 预览发起网络请求；二是「接受不带令牌的 /v1 推理请求」（`inference_open_access`，默认关闭），打开后 `/v1` 接受不带推理令牌的请求，带了令牌的仍照常校验，见[OpenAI 兼容网关的认证](openai-gateway.md#认证)。
- **Web 终端**：开关、空闲超时、并发上限。
- **MCP 服务**：开关、端点与接入示例；开关仅管理员可改。

#### 集成

- **AI 服务**。
- **请求 Trace 导出（OpenTelemetry）**：Collector 地址、加密保存的请求头、采样比例、trace 链接、测试 span 与运行状态。仅管理员可改，见[导出请求 trace 到 OpenTelemetry](../how-to/export-request-traces.md)。

#### 数据保留

设置指标原始样本、容器日志、逐请求记录、Token 用量与长期统计各保留多久。逐请求记录另有容量上限。页面还提供三类长期统计的开关和统计时区，每项旁边显示当前占用。

缩短保留时间前需要确认，超出保留范围的数据在后台删除。仅管理员可修改，详见[查看用量分析](../how-to/analyze-operations.md)。
