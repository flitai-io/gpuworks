## 版本号规则

正式版本使用日历版本号 `vYY.M.PATCH`：`YY.M` 是发布线从 master 切出的年月，`PATCH` 从 0 开始，
同一发布线的补丁版本以缺陷修复为主，修复先合入 master，再回合到发布分支。
每个版本页的“升级须知”列出需要注意的行为变化。版本号与发布流程的完整规则见[发布与内嵌资产](../dev/release.md#版本号)。

## 获取与校验

一键安装脚本 `get.sh` 在 `dl.gpuworks.ai`、阿里云 OSS 与华为云 OBS 中挑选最快的下载源，按 `SHA256SUMS` 校验后再安装；
控制台内的升级读取带 ed25519 签名的发布索引。手动下载时，安装包位于 `https://dl.gpuworks.ai/releases/<版本>/`，
同目录的 `SHA256SUMS` 列出各平台压缩包的校验和。下载源永久保留每个正式版本的安装包，nightly 构建只保留最近 30 个。
