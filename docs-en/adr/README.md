# Architecture Decision Records (ADRs)

Numbers increase by creation time and are never reused once assigned. Some records superseded by later ADRs retain their original text and identify the superseding ADR at the top. Records whose mechanisms have been removed from the code and whose conclusions are carried by later ADRs move to `artifacts/archive/`; this index retains their numbers, links to the original text, and marks them “Moved Out.” New ADRs use the current highest number +1, the filename `NNNN-<kebab-slug>.md`, and the first-line title `# ADR NNNN: <decision>`.
